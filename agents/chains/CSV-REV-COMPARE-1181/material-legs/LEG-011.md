## Material correction

Root cause: `csv-rev-compare-tab.js` used `await file.text()` for every selected input. XLSX is an OOXML ZIP package, so the browser surfaced raw `PK...` package bytes and the table parser then inferred invalid one/two-column schemas.

The hotfix introduces `support-revision-xlsx-ingress.js` and routes `.xlsx` inputs through it:

- reads workbook bytes with `File.arrayBuffer()`;
- loads SheetJS only for XLSX input;
- locates the Support Report table using the same qualification signature (`PIPE` plus Civil Secondary Support semantics in the first 40 rows);
- preserves formula cells as `=<formula>` so primary-support reference identity remains auditable;
- trims to the detected header width and removes trailing blank rows;
- serializes the extracted table to CSV text;
- passes that text into the existing Table-to-Categorized-XML authority;
- leaves CSV/TSV/TXT/paste behavior unchanged;
- adds explicit ingress failure when no Support Report header is found.

The UI file picker now accepts `.xlsx` and reports the selected sheet plus extracted row/column dimensions through the existing toast path.
