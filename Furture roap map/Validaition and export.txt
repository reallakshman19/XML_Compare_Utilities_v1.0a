## [PROMPT 2] Canvas-Based Validation Engine

**Context:**
The Canvas is audited and performant. You will now build a Real-Time Engineering Validation Engine directly into the CAD environment. 

**Your Task:**
Implement a live physics/constraints checker that validates pipeline geometry in real-time.

**Exhaustive Step-by-Step Instructions:**
1.  **Stateful UI Panel:** 
    *   Create a "Design Constraints" panel overlaying the canvas.
    *   Inputs: `Max Slope (%)` (default: 15.0), `Min Soil Cover (m)` (default: 1.2).
    *   *Constraint:* Bind these inputs to an isolated `ValidationState.js` module. Dispatch a `constraintsUpdated` event when changed.
2.  **The Validation Routine (16ms Gated):** 
    *   In `PipelineCanvasManager`, listen for `nodeMoved` and `constraintsUpdated`.
    *   Run `validateGeometry()`, but it *must* be debounced by 16ms (`requestAnimationFrame`) to prevent blocking the main thread during high-speed dragging.
    *   *Slope Logic:* Iterate `edges`. `slope = Math.abs((edge.nodeB.y - edge.nodeA.y) / (edge.nodeB.x - edge.nodeA.x)) * 100`. If `slope > constraints.maxSlope`, flag `edge.hasViolation = true`.
    *   *Depth Logic:* Iterate `Z-depth nodes`. If `value < 0` and `Math.abs(value) < constraints.minCover`, flag `node.hasViolation = true`.
3.  **Canvas Visual Overrides:** 
    *   Update `render()`. If `edge.hasViolation`, override stroke: `ctx.strokeStyle = '#ef4444'; ctx.lineWidth = 4; ctx.shadowColor = 'red'; ctx.shadowBlur = 5;`.
    *   If `node.hasViolation`, override fill to red.
4.  **CAD Tooltips & DOM Syncing:** 
    *   Implement hovering hit-detection. If cursor is over a violating element, render a Canvas tooltip (a rounded `ctx.rect` with `ctx.fillText`) displaying the exact error limit exceeded.
    *   Export a getter `PipelineCanvasManager.currentViolations` returning an array of violating `H(coor)` IDs. The main `pipeline-3d-model-samples.js` table renderer must read this array and apply a red background to the exact HTML row.

**Definition of Done:**
Dragging a Z-depth node past -1.2m instantly turns it glowing red at 60fps. Hovering displays the exact metric failure. The corresponding TSV table row simultaneously flashes red.

## [PROMPT 3] Data Persistence & Project Branching

**Context:**
We must eradicate volatile DOM state. You will implement an IndexedDB local database, a debounced Auto-Save loop, and a Non-Destructive Project Branching system.

**Your Task:**
Execute the persistence layer strictly following these architectural constraints.

**Exhaustive Step-by-Step Instructions:**
1.  **IndexedDB Schema (`pipeline-db.js`):** 
    *   Initialize native `indexedDB.open('PipelineSuite', 1)`. 
    *   Store: `Workspaces`. KeyPath: `id`. 
    *   Data Structure: `{ id: "project-alpha", activeBranchId: "branch-main", branches: { "branch-main": { name: "Base Design", data: { table1: "...", table2: "..." } } } }`.
2.  **Debounced Auto-Save (1000ms):** 
    *   Attach a global `input` listener. Use a strict `1000ms` debounce (clearTimeout). 
    *   When fired, scrape all critical textareas, open an IndexedDB `readwrite` transaction, and `put()` the data into `activeBranchId`.
    *   Inject a non-intrusive `<span id="p3d-save-status">` that flashes *"Saved"* for 2 seconds.
3.  **Branching Interface:** 
    *   Create a `<select id="p3d-branch-select">` and `<button id="p3d-branch-clone">Clone Route</button>`.
    *   *Clone Action:* Deep copy the `activeBranchId` data object. Prompt for a new name. Save as new branch ID. Update `activeBranchId`.
    *   *Switch Action:* On `<select>` change, fetch new branch data, inject into textareas, and force a synchronous `syncSplitTables()` redraw.
4.  **History Stack (Ctrl+Z):** 
    *   Create a strict 50-item array: `const HistoryStack = []; let historyIndex = -1;`.
    *   Take a snapshot on `pointerup` (Canvas) or `blur` (textareas). If `historyIndex` is not at the end of the array when a new snapshot is taken, slice the future history off.
    *   Bind `keydown` for `Ctrl+Z` (undo) and `Ctrl+Y` (redo) to navigate the stack and invoke redraws.

**Definition of Done:**
User can close the browser tab mid-edit, reopen, and instantly recover their exact state. "Clone Route" duplicates the graph safely. `Ctrl+Z` reverses node drags without mutating history out of bounds.

## [PROMPT 4] Professional Import & Export Ecosystem

**Context:**
We must liberate the engineering data from the browser. You will implement Excel parsing, ASCII DXF generation, and PDF reporting.

**Your Task:**
Integrate external data flows using strictly defined libraries and formats.

**Exhaustive Step-by-Step Instructions:**
1.  **SheetJS Excel Ingestion:** 
    *   Inject `https://cdn.sheetjs.com/xlsx-latest/package/dist/xlsx.full.min.js`.
    *   Bind `drop` event to the dialog. `e.preventDefault()`. Parse the `File` object using `XLSX.read()`.
    *   Target sheets named `Sheet_Table2A` and `Sheet_Table3A`. Use `XLSX.utils.sheet_to_csv()`, format tab spaces, and inject directly into the raw `<textarea>`s. Force redraw.
2.  **ASCII DXF Generator:** 
    *   Do not use heavy external DXF libraries. Write a raw ASCII DXF string generator.
    *   Output the required DXF structure: `0\nSECTION\n2\nHEADER\n0\nENDSEC\n0\nSECTION\n2\nENTITIES\n...`
    *   Loop `Table2X` interpolated points. Generate an `LWPOLYLINE` entity.
    *   Loop `Table3X` markers. Generate `TEXT` (node names) and `CIRCLE` (nodes) entities at the exact X/Y coordinates.
    *   Blob export: `new Blob([dxfString], { type: 'text/plain' })`.
3.  **PDF Deliverable (jsPDF):** 
    *   Inject `jspdf.umd.min.js` and `html2canvas.min.js`.
    *   *Page 1:* Title "Pipeline Route Summary", Date, and Total Length calculation.
    *   *Page 2:* Call `html2canvas` on the Canvas DOM node. Inject the resulting base64 image into the PDF using `doc.addImage()`. 
    *   *Page 3:* Iterate Table 3X. Use `doc.text()` in a tabular loop to print "Bill of Materials: Structural Markers".
    *   Blob export: `doc.save('Pipeline_Report.pdf')`.

**Definition of Done:**
Dropping a `.xlsx` file bypasses the text areas and draws the graph instantly. The generated `.dxf` opens natively in AutoCAD without corruption warnings. The `.pdf` contains high-fidelity screenshots of the CAD canvas.
